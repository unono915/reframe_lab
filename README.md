# 다시봄 (Reframe Lab)

> 사용자가 일상의 장면을 스스로 관찰하고 질문하며 문제를 재정의하도록 돕는
> 매일 5~10분의 AI 사고 코칭 PWA.

## 개요

일상에서 당연하게 지나치던 장면을 다시 보고, 하나의 현상을 여러 관점에서 다시 정의하는 훈련을 제공합니다.
모바일 웹앱과 iPhone 홈 화면 설치형 PWA 환경을 주요 대상으로 합니다.

## 상태

초기 설정 단계입니다. 애플리케이션 코드는 아직 포함되어 있지 않습니다.

## 문서

제품 기획서(PRD), 디자인 스펙, 개발 계획 등 내부 문서는 저장소에 포함하지 않고 로컬에서만 관리합니다.
